Step By step of how to use Github By Dean Ebiri:
1. Download git by going to https://git-scm.com/, then click of the download option for your specific system
2. Open the .exe file that was downloaded, accept all the default options such as the editor, path setting, and then install.
3. When the installation is complete, type git --version in command prompt, this will allow you to verfiy that the correct version was downloaded. If can see the version you need, that means that git was successfully installed.
4. Go to the git hub website @ https://github.com
5. Click on the Sign up option, enter your email, password and Username(this is very important so name it appropriately), verify your email to complete the set up.
6. To configure git run the following command in command prompt or your Terminal of choice.
7. git config --global user.name "your git hub Username"
8. git config --global user.email "your git hub email"
9. With this you have successfully installed and configured both Git and Github.
10. Next you can add your Github repository to VS code or any editor of choice if you wish to do so.
11. Open the VS code, make sure to install Vs code first, go to the extensions panel.
12. Search for Git hub pull requests and Issues, then Install the extension.
13. In VS code, hit CTRL + SHIFT + P, type Git: Clone.
14. Vs code will ask you to go to your GitHub repo, copy the HTTPS url and paste it into VS code.
15. Locate the folder on your computer that contains the repo, Vs will then open the cloned repository.
